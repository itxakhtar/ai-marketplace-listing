# Sample images

Put your own product photos here (JPG/PNG/WEBP; `.jfif` is accepted too). Photos are **not** committed
(personal data / licensing). Good demo set: a phone, a tablet, shoes, a watch, a laptop.

```powershell
python -m scripts.day2_run_samples      # runs every image in this folder
python -m scripts.edge_cases --folder sample_images   # offline quality check, no API calls
```
